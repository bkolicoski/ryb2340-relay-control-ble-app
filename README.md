# Reyax RYB2340 Bluetooth Control App

A modified Android app for wireless control of devices using the Reyax RYB2340 BLE module.

## Key Features
- Simple toggle buttons for relay control
- Connection status monitoring
- Message log display

## Setup Instructions
1. Open the app and select your module from the scan list
2. Use the ON/OFF buttons to control your connected device

## Compatibility
- Requires Android 5.0+ (BLE support)
- Designed for Reyax RYB2340 modules
- Works with the Arduino/ESP8266 setup shown in the tutorial

For the complete hardware tutorial and wiring guide, watch the companion video:  
[YouTube: The Easiest Way to Add Bluetooth to Arduino & ESP8266 with RYB2340](https://youtu.be/ynRzGscDZ88)

The Arduino source code for the ESP8266 is available [here](https://www.tastethecode.com/ryb2340-add-bluetooth-to-any-project-in-minutes)

> Note: This app is based on Reyax's official demo app with UI modifications for simpler control.
